# Security Policy

## Reporting a security issue

Please do **not** publish wallet secrets, private keys, seed phrases, credentials, tokens, RPC passwords or exploitable production details in a public GitHub issue.

For security-sensitive reports, contact the LKCT project through the official Lajkto contact channels at:

https://lajkto.eu

## Scope

This repository contains a reviewed subset of the LKCT consensus source. The absence of an internal service-layer component from this repository does not mean that component is part of the public security-review scope.

## Verification

Official wallet downloads should be obtained from:

https://lajkto.eu/lkct

Use the SHA-256 checksum files published alongside releases when available.
